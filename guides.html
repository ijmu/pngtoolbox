Guides: PNG, WebP and the file-size decisions behind them

Fifteen guides, grouped by the decision you are trying to make rather than by keyword. Each one explains the mechanism, then tells you what to do.

By PNGToolbox Editorial Published 2026-10-22 Last reviewed 2026-10-22 How we test

At a glance

  • Start with the format decision if you do not yet know what output you need.
  • Start with the benchmark if your question is "how much bigger will this get".
  • Start with the transparency guides if something with alpha looks wrong after a conversion.
  • Every quantitative claim traces back to a test whose script and CSV we publish.

Where to start

Most people arrive with one of four problems: a file that will not open somewhere, a file that is too large, a transparent image that lost its transparency, or a format choice they have to justify. The library below is grouped that way.

If you only have a minute, the WebP to PNG benchmark answers the size question with measured numbers, and the converter does the conversion locally in your browser.
