What PNGToolbox does with your images

PNGToolbox converts WebP files to PNG or JPG and removes solid-colour backgrounds from PNG and JPG images. Every one of those operations runs inside your browser using the Canvas API. Your files are read from your device, decoded, re-encoded, and handed back to you as a download. They are not uploaded to a PNGToolbox server, and there is no PNGToolbox server that accepts image uploads.

This is a technical property of how the tool is built, not a promise about intent: the page contains no upload endpoint, and the conversion code calls URL.createObjectURL on your local file rather than fetch. You can confirm this yourself by opening your browser's network panel while converting a file and observing that no request carries your image.

What is never collected

  • Image contents — pixel data never leaves your device.
  • Filenames — the tool uses the name only to label your download, locally.
  • File counts or sizes — batch size and output measurements are displayed to you and not transmitted.
  • Accounts — there is no sign-up, login, or user profile anywhere on this site.

What is stored on your device

PNGToolbox stores a single preference in your browser's localStorage: your light or dark theme choice. It contains no identifier and is not readable by any other site. Clearing site data in your browser removes it.

The site registers a service worker that caches page HTML and static assets so repeat visits load quickly and the tools keep working on a poor connection. That cache holds only PNGToolbox's own files — never the images you open. Unregistering the service worker or clearing site data removes it.
